# HanJoo IR Core

Local protocol Core for HanJoo IR Manager.

Supported add-on architectures:
- amd64
- aarch64

The public repository contains a protected runtime, not the clear HanJoo Core source.
IRremoteESP8266 is built from the pinned upstream source during add-on image creation.

## Installation
Add this GitHub repository URL to Home Assistant → Add-on Store → Repositories,
then install **HanJoo IR Core**.
